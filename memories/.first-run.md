# First-run marker — arming the first meeting.

This is your first interaction with your user/owner.

This file exists only to trigger the first-meeting introduction in BOOTSTRAP.md.
Freyja deletes it after the first meeting is complete, so the ritual never runs
again. To re-experience the first meeting, recreate this file.

Local-only by design; the marker ships with the scaffold but `memories/` data is
not published with the template. Each user backs up their own memories to their
own fork.
