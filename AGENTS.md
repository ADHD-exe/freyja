# AGENTS.md — operating Freyja's memory system

`memories/` is a **local-only** experimental memory system. It is ignored by git
and must never be committed or published. This file describes how to operate it.

## Layout

- `memories/current/` — session notes, one per session: `YYYY-MM-DD_topic.md`
- `memories/core/` — permanent memories, one file per topic
- `memories/old/` — archived session notes (done notes after 1-day grace, idle open notes after 14 inactive days)
- `memories/scripts/` — helper scripts (run from the repo root with PowerShell)
- `memories/templates/` — canonical file formats (core / project / task)
- `memories/INDEX.md` — auto-generated searchable index (regenerated by `archive.ps1`)

## Scripts

| Script                | Purpose                                                        |
| --------------------- | -------------------------------------------------------------- |
| `new-memory.ps1`      | Create a memory note (`-Bucket current` or `-Bucket core`)     |
| `promote-memory.ps1`  | Move a current note to core (`-FileName <topic>` -NewName <n>) |
| `search-memory.ps1`   | Grep all memories for text (`-Query <text>`); recall bumps mtime on `current/` |
| `close-memory.ps1`    | Mark notes done (`-Filter <partial>` / `-Tag <tag>`), then archive  |
| `archive.ps1`         | Relevance-based archive: done notes after grace, idle open notes after inactivity; rebuild INDEX |
| `consolidate.ps1`     | Run archive + write a promotion-candidate report (default 2 days) |

Examples:

```powershell
.\memories\scripts\new-memory.ps1 -Bucket current -Topic "task_name" -Tags "task" -Summary "one-liner"
.\memories\scripts\promote-memory.ps1 -FileName "task_name" -NewName "task_name"
.\memories\scripts\search-memory.ps1 -Query "linux"
.\memories\scripts\archive.ps1 -InactivityDays 14 -DoneGraceDays 1
.\memories\scripts\close-memory.ps1 -Tag "project:openclaw-review"
.\memories\scripts\consolidate.ps1 -InactivityDays 14 -DoneGraceDays 1 -CandidateDays 2
```

## Rules

- **Write** a `current/` note at the end of any session with lasting content:
  a substantive summary, decisions and reasons, and code locations.
- **Search** before assuming: if a topic may relate to earlier work, run
  `search-memory.ps1` first.
- **Promote** to `core/` only facts that losing would genuinely hurt (stable
  user preferences, recurring workflows, key decisions). Never promote routine
  noise.
- **Never store secrets or API keys** in memories; note where credentials live
  (file path) rather than the values.
- Core memories are permanent — be accurate and complete.
- `memories/freyja.md` is the sanitized operational persona copy; `Freyja.txt`
  at the repo root is canonical for publishing. Keep their relationship
  intentional, not accidental.
